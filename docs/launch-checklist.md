# 런칭 당일 체크리스트 (계획서 Step 8)

작성 2026-10-13 · 근거: [배포 준비 계획](launch-plan.md)의 H1~H8 · 절차: [README](../README.md#배포--flyio) · 운영: [운영 매뉴얼](operations.md)

**읽는 법** — □ = 아직 안 함, ☑ = 끝남. 끝내면 □ 를 ☑ 로 바꾸고 "완료 증빙" 칸에 확인할 수 있는 근거(번호·날짜·화면 위치·커밋)를 적는다.
증빙 없이 ☑ 로 바꾸지 않는다(`node --test` 의 `launch-docs.test.js` 가 증빙 칸이 빈 ☑ 를 잡는다). 실제 번호·키 값은 적지 말고 "어디서 확인되는지"만 적는다.
**1·3 절에 □ 가 하나라도 남아 있으면 런칭(유료 광고 판매 공개)하지 않는다.**

## 3. 런칭 당일 기술 점검 (배포된 운영 서버에서)
순서대로. 하나라도 실패하면 거기서 멈추고 [운영 매뉴얼 장애 대응](operations.md#장애-대응)대로 고친 뒤 다시.

| 상태 | 항목 | 완료 증빙 | 막히면 영향 |
|---|---|---|---|
| □ | 운영 시작 점검 통과 — `fly logs` 시작 줄에 `운영모드=켜짐`, `[config]` 오류 줄 없음 | | 운영 모드가 꺼져 있으면 사업자 정보·토큰 강도·결제 점검이 다 빠진 채 돈을 받게 된다 |
| □ | `FREE_MODE`·`DEV_DEPOSIT` 꺼짐 — 시작 줄 `테스트모드=꺼짐, 모의입금=꺼짐`, `fly secrets list` 에 두 이름 없음 | | 켜져 있으면 결제 없이 광고가 붙는다(운영 모드면 시작 자체가 거부됨) |
